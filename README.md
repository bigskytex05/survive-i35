# Survive I-35

A humorous low-poly arcade racer about surviving the I-35 corridor between Austin and Dallas.
Godot 4 (GDScript), Compatibility renderer, targets Android and web.

- Design spec: [`GAME_DESIGN.md`](GAME_DESIGN.md)
- Choices made along the way: [`DECISIONS.md`](DECISIONS.md)

**Status:** Phases 1, 2, 4 and 5 complete (5, cars and props, and 4, police, were built ahead
of Phase 3 on request). The game opens in the garage: pick the Truck, SUV or EV and a paint,
then the Radar Detector, Censored Gesture or High Beams, then drive level 1, "Kickoff": from
Round Rock to the stadium parking lot in Austin, 5.6 km in 3:00, past three hidden speed traps.
Take the stadium exit; the finish line is the lot's gate.
Music: "Highway Momentum", plus synthesized sound effects (engines, tires, crashes, sirens),
with mute and volume sliders (M mutes). Construction (Phase 3) is next.

## Play the test build

https://bigskytex.cloud/survive-i35/

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Steer | A / D or Left / Right | Left stick, d-pad | Arrow buttons (bottom-left) |
| Gas | W or Up | Right trigger | GAS |
| Brake / reverse | S or Down | Left trigger | BRAKE |
| Prop | Space | A | PROP (hidden for the passive Radar Detector) |
| Pause / Restart | Esc or P | Start | Pause button |
| Mute | M | Back / Select | Speaker button (volume slider next to it) |

On desktop, press **T** to show the touch controls and try them with the mouse.

In the garage: arrows / d-pad / tap to pick, Enter / A or Next to move on, Esc / B to go back.

Beat the clock to the stadium lot. Hard hits spin you out; squeezing past cars at
speed (less than ~1 m to spare) adds +0.5 s.

**Police.** The limit is 75. Troopers hide off the right side of the road (behind a billboard,
under a live oak, or in an overpass's shadow); watch for the glint off a windshield and for
traffic braking. Pass within 60 m of one at more than 80 mph and it comes after you. If it stays
alongside for 2 s you're pulled over: a ticket and 15 s off the clock. Stay 120 m ahead of it for
8 s (traffic slows it down too) and you've lost it. Hitting, high-beaming or flipping off a
trooper also starts a chase, radar detector or not.

| Prop | What it does |
|---|---|
| Radar Detector | Passive: speed traps can't clock you; its LEDs and beeps say when one is near. It won't stop a chase you start some other way |
| Censored Gesture | Nearest driver within 15 m swerves at you. Usually they wreck and take 1-3 cars with them; sometimes they connect. Brake or steer to dodge. 8 s cooldown |
| High Beams | 4 s of light. Drivers ahead in the beam slow down and wander until 3 s after it leaves them. 10 s cooldown |

## Run it in the Godot editor

1. Install Godot 4.4 or newer (standard build, not .NET).
2. Open the project folder (`project.godot`) and press **F5** (the main scene is the garage,
   `scenes/main/Garage.tscn`). F6 on `scenes/race/Race.tscn` drives straight away with the SUV.

## Tests

```bash
tools/run_tests.sh        # headless: road, driving, traffic, race flow, cars, props, garage, sites, audio, police
SUITE=test_police tools/run_tests.sh                  # just one suite
tools/run_balance.sh      # an autopilot drives Kickoff on 5 traffic seeds and reports time left
CAR=res://data/cars/truck.tres tools/run_balance.sh   # same, in another car
SKILL=1 tools/run_balance.sh                          # a confident driver instead of a careful one
TRAFFIC=0 TRAPS=0 tools/run_balance.sh                # empty road, no speed traps
```

## Sound effects

```bash
tools/make_sfx.sh         # re-synthesizes assets/audio/sfx/*.wav and reimports them
```

Every effect is generated by `tools/make_sfx.gd`; drop a real recording with the same file name
over any of them to replace it.

## Build for the web

```bash
tools/build_web.sh        # -> build/web/ (no threads: runs on any static host, e.g. itch.io)
```

The script also patches Godot 4.4's exported web audio player so looping sounds loop without a
gap (see DECISIONS.md, "Sound effects").

Set `GODOT=/path/to/godot` if the binary isn't `godot4` on your PATH.

## Where things live

| Path | What |
|---|---|
| `autoload/Palette.gd` | Every color in the game |
| `resources/CarData.gd`, `data/cars/*.tres` | Car stats and traits (add a car = add a `.tres` + list it in `Garage.tscn`) |
| `resources/PropData.gd`, `data/props/*.tres`, `scenes/props/` | Props: data, plus a behavior script extending `Prop` |
| `scenes/main/Garage.*`, `autoload/GameState.gd` | The garage, and the loadout it hands to the race |
| `autoload/AudioManager.gd`, `assets/audio/` | Music, buses, music and effects volume, mute (saved to `user://settings.cfg`) |
| `core/Sfx.gd`, `scenes/race/RaceAudio.gd`, `tools/make_sfx.gd` | Sound effects: playback helpers, the race's sounds, and the synthesizer that makes them |
| `scenes/police/`, `data/traffic/police.tres` | Speed traps (`SpeedTrap`), the trooper AI (`PoliceCar`) and chases (`Police`) |
| `scenes/sites/`, `core/Scenery.gd` | Start and finish set pieces (Round Rock, the stadium lot) and their builders |
| `resources/LevelData.gd`, `data/levels/*.tres` | Levels: route, clock, traffic, speed traps, funny lines |
| `resources/TrafficCarData.gd`, `data/traffic/*.tres` | Traffic types (add one = add a `.tres` + list it in `TrafficSpawner.tscn`) |
| `core/Corridor.gd` | Towns and their I-35 mile markers |
| `scenes/traffic/` | Traffic AI (`TrafficCar`), spawning/pooling (`TrafficSpawner`), collisions, behaviors |
| `scenes/road/` | Road math (`RoadGeo`, `RoadSpec`), streaming (`RoadManager`), chunks |
| `scenes/race/` | Race flow, clock, route markers, car controller and placeholder model, camera, HUD |
| `scenes/ui/` | Touch controls, pause menu, results screen, progress strip, popups, vignette, prop dial, radar box, censor overlay, pursuit meter, ticket card |
| `core/` | Mesh builder, shared materials, UI theme |
